# Design Specificity Verdict

**LLM assessment:** Deeply authored; not transplantable to a generic dashboard. Bespoke token system with a stated theory ("Porcelain by day, Onyx by night", styles.css:37–354); verdicts as burnt-amber/field-green judgements rather than error/success; ledger-as-instrument metaphor; verdict counts as glowing dark-mode "lamps"; BR-nnn citation pills wiring conclusion ↔ ledger. The flip side: the language is private and nothing teaches it.

**Deterministic scan:** 2 warnings only — side-tab accent border (styles.css:672) and "Instrument Sans" on the overused-font list (styles.css:24; deliberate pick from the approved restyle, accepted). 0 hardcoded colors in TSX, 4 inline styles (all legitimate dynamic widths), 156 aria attributes vs 32 buttons, tokenized 7-step type scale with one `.9em` escape. Scan strongly corroborates the discipline Assessment A found.

**Browser evidence:** Static build screenshots (no backend running) confirmed layout renders; caught raw `Unexpected token '<' … is not valid JSON` surfaced verbatim in the error banner — a jargon leak the review's "verbatim server words" policy doesn't excuse. No overlay injection available (no native browser automation; static-only serve).

# What's Working

1. Token/material system (styles.css:37–354): components are theme-blind ("what is a row made of"), producing a dark mode with an actual idea (verdict lamps), corroborated by a near-clean detector run.
2. Epistemic honesty as visual language: withheld provisional verdicts, skeletons instead of invented names, "not grounded" warnings, no invented timestamps — the UI enacts the trust claim.
3. WhatChanged + answersBehind (ReviewDetailPage.tsx:137–280): attributing moved verdicts to the reader's own quoted sentence is the most persuasive screen in the product.

# Minor Observations

Bare Loading/ErrorPanel returns skip page column (ReviewDetailPage.tsx:660–661); inconsistent error rendering (review-questions.tsx:362); "Examples fill both rails" copy leak; info-bearing native title tooltips; VerdictBand at 4+ facts is the busiest element on the page; comment-essay style would make a free DESIGN.md.

# Questions to Consider

3. Held verdicts hide behind a binary curtain — would per-verdict contingency (already encoded in `hinge`) be more honest?
